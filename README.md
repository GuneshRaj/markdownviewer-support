# Markdown Viewer — Support

**Markdown Viewer** is a free Markdown & MDX viewer and editor for macOS with
live split editing, on-device AI chat, and PDF/HTML export.

## Get help

- 🐛 Found a bug or have a feature request? [Open an issue](../../issues)
- 🔒 [Privacy Policy](PRIVACY.md) — short version: the app collects no data at all

## FAQ

**Which files can it open?** `.md`, `.markdown`, `.mdown`, `.mkd`, `.mkdn`,
and Markdown Packages (`.mdx`, `.xmd` — a zip of markdown files plus images).

**Does the AI send my documents anywhere?** No. Chat with AI uses Apple
Intelligence entirely on your Mac (requires macOS 26 with Apple Intelligence
enabled). Every other feature works on macOS 14+.

**How do I make it the default app for markdown files?** File → Set as
Default for Markdown Files… inside the app.
